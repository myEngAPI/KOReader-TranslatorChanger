## 📚 KOReader-TranslatorChanger

KOReader-TranslatorChanger
KOReader小司机翻译配置

本插件为KOReader翻译引擎切换。因KOReader自带翻译为Google，在国内无法使用，本插件协助KOReader切换可用翻译引擎。
目前支持的引擎有：
- **DeepL**
- **DeepSeek**

## 📥 安装

To install the plugin:

1. 下载**最新版** [GitHub repository](https://github.com/myEngAPI/KOReader-TranslatorChanger/releases/).
   国内下载：https://xiaosiji.lanzouw.com/b0nzto0na 密码:aa6k
3. **解压** 然后解出`xiaosiji_translator.koplugin` 目录.
4. 拷贝 `xiaosiji_translator.koplugin` 目录.
5. 把它放在你设备的`koreader/plugins/` 目录下。

---

## 🔧 设置

1. 打开KOReader.
2. 在**主目录 > 工具（x型扳手） > 第二页 > 小司机翻译配置**.
3. 如是**DeepL**，在API密钥里填入DeepL密钥即可。
4. 如是**DeepSeek**，**只要**填入**API密钥**即可。
5. 如是**其他大模型**，Base URL需要修改，然后填入**API密钥**即可（**该步未测试，理论上可以**）。
6. 在DeepL上方选择翻译引擎，默认为Google翻译，重启后可用。
